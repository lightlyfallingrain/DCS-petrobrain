### cockpit actions (generally, not just 9K113)

Consider these a list of items to do, swithces to flip, buttons to push. Between each, 1 s delay (make that a constant that can be easily changed) simulating that Petrovich moves his hand from switch to switch.
While looking through 9K113, Petrovich can use the 9K113 slew cockpit commands. Flipping other swithes makes him not look through the 9K113 and therefore *not see* what 9K113 shows.
  - Look through 9K113 -> need to flip a switch -> take eyes away and move hand to switch (simulated by 1 s delay) -> flip switch -> move back to look through 9K113 (simulated by 1 s delay).

## sight ready

When warmup (or is it calibration or what) is done in about 3 minutes, a light in the guidance unit panel will illuminate telling that the unit is ready. Tell the pilot "Guidance unit ready".

## "Observ"

Observ is a shorthand for using the 9K113. "Observ" may be a difficult word for STT, so well allow synomyms like "look closer" "check" "observe".

### When to Observ

- When pilot requests it
- Autonomously given conditions
  - TDB

### Observing

- Turn on OBSERV in guidance unit, tell pilot "Observ on"
- Wait X seconds for gyro alignment. X can be found it the documents.
- Slew 9K113 to where we want to look.
- Petrovich can alternate between naked eyesight, binoculars and 9K113 as necessary. While naked eyesight or binoculars are used (at wherever) 9K113 stays slewed at it's last position automatically (that's a feature of the 9K113). Unless it reaches gimbal limits, of course. 9K113 slew controls are to be used _only when looking through it_.
- OBSERV should not be left on for prolonged periods unless it is needed. It's sensitive to damage and dirt, so while that's not simulated in DCS, let's not keep it on all the time and instead aim to protect it.
- 9K113 slew is not instantenous, it takes some time to move. Therefore inspect and adapt is used here: is it pointing at correct location? yes/no -> adjust.
  - ownship telemetry must contain 9K113 data.

### No longer oberving

- When?
    - By pilot command "Observ off". Note the synonyms as well.
    - By strong manouvres, to not damage the gyros.
- Switch OBERV to OFF position.
- Tell the pilot "Observ off".


# 9K113 simulation

9K113 has wide and narrow FOV. Angles already harvested into docs and available in the Quickstart guide.
The function to simulate is
- Zoomed in view of the target, making datection, classification and type identification possible at greater range. See calibration tables recorded earlier.
- Gives good understanding of azimuth relative to ownship.
- Gives poor understanding of vertical angle relative to ownship.
- Has a distance measurement visual aid that is usefull <= 5km. To simplify, we could have a linearly decreasing error in distanse as unit gets closer.
- Allows keeping the optic crosshair on exactly on target by slewing the optic as the target moves.
- The optic is gyro stabilized, so ownship movement is canceled out.
  - Gyros are sensitive to violent manouvres and OBSERV must be swithced OFF is pilot manouvres violently. (~1-2s reaction time here is fine and realistic)
- Pilot will see where 9K113 is pointing via the ASP-17 sight, given that the 9K113 target is within the HUD limits.
- Autonomous wide and narrow mode usage.

## attack

### ATGM

For ATGM attack, the copilot keeps the target unit in 9K113 crosshairs. Target movement must be taken into account and 9K113 kept slewing at target speed so it keeps pointing at target. (Inspect adapt loop)
When attack run starts:
- Check OBSERV is ON.
  - If OBSERV is OFF, turn it ON and tell pilot "Observ on, wait"
  - Wait for the alignment period before slewing the sight.
- Turn weapons circuits switch to ARMED.
- Select a pylon with a missile on it (typically the next one) by turning the pylon selection knob. A light in the weapon selector panel indicates missile present.
- Slew 9K113 to target if not already.
- Do normal azimuth only guidance callouts.
- When belief about range is beyond ATGM range, say "out of range". Once only.
- When belief about range is within ATGM range, say "in range". Once only.
- When missile is fired (pilot fires currently), say "<missile type word>, <estimated missile flight time in seconds>" e.g. "Ataka, 7 seconds"
  - estimated seconds = distance to target / missile speed.
  - I'm not sure it there's one or more ATGM's that are supported. Find out from the Quickstart document.
- When missile impacts (target or otherwise) say "impact". If we can detect hit/miss say "impact hit/miss".
  - impact detection probably through the missile as world object vanishing.
- After impact 1s delay then reset the guidance unit transmitter by pressing the button for that purpose.


### rockets and generally target position

- 9K113 is not intended to guide a rocket attack, but it could be used to help the pilot align with the target.
  - By copilot keeping the 9K113 crosshairs on the target unit, the pilot can use the ASP-17 to see where the target is. Pilot then flies the rocket attack. When pilot starts turn away, OBSERV OFF.
- Similarly, 9K113 can be used to pinpoint unit location to pilot. Pilot has to fly so that the unit is visible in the HUD so he can see where the ASP-17 marks the 9K113 pointing. This at player request.


# Weapons safety circuit switch

This should be it's own roadmap item before ATGM attack run.

Copilot has the weapons safety switch. A master arm in other words. It has to be flipped on and off as needed.

Player: "weapons on" / "master arm on" / "weapons hot" -> Copilot turn weapons safety cirtuit on ARMED.
Player: "weapons off|safe" / "master arm off|safe" / "weapons cold|off|safe" -> Copilot turn weapons safety cirtuit on SAFE.
