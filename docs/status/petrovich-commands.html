Petrovich Command Map

Every deterministic voice command on main, updated 2026-10-21. Read left to right: say the words on each node in order. Dashed arrows are optional parts; skip any of them.

1 Every transmission

Nothing happens until you release PTT. Starting with “Petrovich” makes it free speech for the brain instead of a command. Ending with “nevermind” throws the whole transmission away.

flowchart LR
  PTT(["press PTT"]) --> Q{"first word
Petrovich?"}
  Q -- "petrovich / hey petrovich" --> BR["free speech → brain layer"]
  Q -- no --> CMD["command — cards 3 to 8"]
  CMD --> REL(["release PTT → acted on"])
  BR --> REL
  CMD -.-> NV(["… nevermind / never mind / disregard"])
  NV --> X["nothing happens"]

3 Search F10

Points Petrovich's search. Clock and bearing are relative to the nose and to north respectively. F10 has ahead/left/right/full and the compass points.

flowchart LR

  L(["look"]) --> A
  S --> F["full · all around"]
  FS(["full scan"])
  S --> CK["8 … 4  o'clock"]
  S --> CP["north … northwest"]
  S --> B(["bearing"]) --> D["three digits, 5° steps
“three two zero”"]
  CS(["cancel scan / stop scan / stop scanning"])

5 Ask what's out there

One slotted command. Use any, all or none of the three slots; “report” and “describe” are the same. With no slot he summarises everything.

flowchart LR
  R(["report / describe"]) -.-> WHAT{{"what"}}
  R -.-> WHERE{{"where"}}
  R -.-> FAR{{"how far"}}
  R --> ALL["nothing more = everything"]
  WYS(["what do you see"]) --> ALL
  R --> B(["bearing"]) --> D["three digits"]

6 Attack run

Select a target, step the selection if he picked the wrong one, then engage. Guidance is o'clock and “come left/higher”; silence means lined up.

flowchart LR
  ST(["select target / set target"]) --> WHAT{{"what"}}
  ST --> WHERE{{"where"}}
  ST -.-> FAR{{"how far"}}
  STP(["step"]) -.-> N["one … nine"]
  STP --> DIR["left · right
near / closer · far / further / away"]
  N --> DIR
  EN(["engage / engage target"]) -.-> SL["what · where · how far"]
  EN -.-> WP["guns · rockets · missiles"]
  EN ==> ARM["also sets weapons ARMED  ⟵ new"]
  DT(["drop target"])
  DG(["disengage / stop attack / abort"])

7 9K113 sight & weapons new

After takeoff Petrovich powers the guidance unit up by himself and says “Guidance unit ready”. Observ on before that gets “Unable, guidance unit not ready.”

flowchart LR
  AUTO["after takeoff (automatic)"] --> RDY["“Guidance unit ready”"]
  OB(["observ / observe"]) --> ON["on"]
  OB --> OFF["off"]
  RDY -.->|"needed first"| ON
  WP(["weapons"]) --> AR["armed  ⟵ new"]
  WP --> SF["safe  ⟵ new"]
