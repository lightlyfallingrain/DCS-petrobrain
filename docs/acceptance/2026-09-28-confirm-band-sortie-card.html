Why this card exists. Last sortie: "cancel" → "Cancel everything, confirm?" → "yes" / "confirm" → "Unable, no such command." The confirm band could not be answered at all. Three defects behind that one symptom, fixed here and reviewed five rounds deep in code — but none of it has been flown. Static review can't settle timing or whether cancel actually stops the task.

Optional fold-in. You may fly this inside 2026-09-25-crew-behaviour-sortie.md instead — its "Cancel everything" block already says cancel and confirms it, so every cancel there exercises this fix too. Your call.

Test cases

1 Cancel, confirmed three ways

Do
Issue any task (e.g. scan left), say cancel. When asked "Cancel everything, confirm?", answer "confirm". Repeat twice more, answering "yes" then "roger".
Expect
All three words accepted, no "unable, no such command" — and the task actually stops each time.
Bring back

2 Timing worth most

Do
A few times over the sortie, say cancel and answer at your normal pace — not rushed, not deliberately slow. 15s to answer, 20s late-grace, both reasoned budgets, never measured against a real cockpit.
Expect
Never hear "Say again?" when you believe you answered promptly.
Bring back

3 Negative leaves it running

Do
Issue a task, say cancel, answer "negative". Repeat with "no", then "disregard".
Expect
Task keeps running, all three times — nothing stops.
Bring back

4 A command is still a command

Do
Say cancel. While the confirm question is still open, say an ordinary command that isn't an answer word — e.g. "okay scan left".
Expect
It acts as the command (scan starts), not swallowed as an answer to the open question.
Bring back

Debrief list

  1. All three affirmatives (confirm/yes/roger) accepted, task genuinely stops?
  2. Any "Say again?" on an answer you thought was prompt — and roughly how late was it?
  3. All three negatives (negative/no/disregard) correctly leave the task running?
  4. Any command swallowed as a confirm answer instead of firing?

Anything that surprises you is worth more than anything on this list.
