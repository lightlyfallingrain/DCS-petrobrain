2 · Edit the readback

Do

On the ground, open body-layer/config/rules/flight.lua and change the spoken readback line. Save it. Restart the mission — not body-layer. Say "turn left two zero" again.

3 · A clash between two rules

Do

Add a second rule under a different id but the exact same wording as "turn left/right NN." Restart the mission. Say "turn left two zero."

Expect

One "Action file error." on the intercom, and the command does nothing — not "say again," not silence. Remove the duplicate, restart again — the command works.

Record

Was "Action file error" clearly audible and distinct from ordinary radio chatter?

4 · A typo in the Lua

Do

Put a syntax error into flight.lua (an unmatched quote is enough). Restart the mission.

Expect

The same single "Action file error" line, once. The real complaint — which file, which line — only shows up in the log, not on the intercom. Fix it and restart; the command comes back.

Record

Did you need to look at a log to understand what broke, or could you tell from the cockpit alone?

5 · Edge phrasing

Do

Try "uh, turn left two zero" (a filler word). Try "turn left thirty" (a number word, not digits). Try "the tanks are on the ridge" (ordinary speech, not a command).

Expect

Filler word: still works. "Thirty" as a word: falls to "say again" (same as before this change — it never understood number words here either). The tanks sentence: never treated as a command.

Record

Any of the three behave differently than expected?
