Effector Readbacks

The four switch-sequence readbacks (“Observ on.”, “Observ off.”, “Weapons armed.”, “Weapons safe.”) used to be fixed strings returned the instant the command was heard. They now come from the sequence files themselves, spoken only once the switch has actually finished moving — a poll later, as a confirmation the action is done, not an echo of the command.
