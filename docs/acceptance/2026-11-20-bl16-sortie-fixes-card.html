Two things this card does not cover: the slip-ball probe has its own card (see “Also on this flight” below), and the mission-wide running command number is still open BL-16 work, not built in this batch.

Pre-flight gate — do this first

After your usual redeploy and restart, before takeoff
source run-scripts/petrobrain.env
curl -s http://$DCS_COLLECTOR_IP:7791/flight_control/latest
curl -s http://$DCS_COLLECTOR_IP:7791/ai_pilot_wheel/latest
Both return a real JSON object. The collector's startup log shows no “Export.lua version mismatch” warning (EXPECTED_EXPORT_VERSION = "2026-11-20"). If either fails, stop — the deploy did not take and nothing below will mean anything.

1 Mode 1 take — no pedal kick, wings level

Do
Unparked, straight and level, “you have controls.”
Expect
No left-pedal kick on the take. Once settled, holding a heading means wings level (bank ~0°), not a standing bank held by crossed controls. Previously: left pedal drifted, right bank compensated, heading held with unwanted yaw+bank.
Record
Bank angle a few seconds after the take; any pedal movement you didn't command.

2 Re-take

Do
“I have controls,” then immediately “you have controls” again.
Expect
The second take confirms and flies cleanly — not “unable, not ready” while Petrovich is, in fact, able to take.
Record
Did the re-take confirm normally, any stray bank/pedal left from the first cycle?

3 “I have controls” actually frees the stick

Open question from your own prior flight note — say plainly what you see, not just pass/fail.
Do
While Petrovich holds mode 1, “I have controls,” then move the stick yourself immediately.
Expect
The aircraft responds to your input right away, nothing fighting you.
Record
Was the handback clean, or did anything feel like it was still being held?

4 Mode 2 — turn after a break, and during a break (latest wins)

Do — after
“Break turn left,” let it finish, then “turn right 30.”
Do — during
“Break turn right,” and before it finishes, “turn left 15.”
Expect
Both turns are flown — a heading goal always wins, whether it arrives after a finished break or interrupts one still running. Before this fix: any goal after the first break was acknowledged but never flown.
Record
Did both cases actually turn, and did the overlay leave CBTM for FLT each time?

5 “Altitude 100” sets exactly 100

Do
“Altitude 100 radar.”
Expect
The wheel's set value reads exactly 100, not a nearby number (previously saw 116 commanded as 100). The flown value may wander a bit — that's allowed. Watch a few seconds for hunting.
Record
The set value shown, and whether it ever stopped moving/hunted.

6 Collective holding altitude in a break, mode 1

Do
Mode 1, “break turn left” (or right).
Expect
Collective is now written in mode 1 — altitude should hold noticeably better through the break, with less speed lost, than before this batch.
Record
Rough altitude loss and speed loss through the break, compared with what you remember before this batch.

7 Pedal into turns, mode 1 — note direction

Do
Mode 1, “turn right 30,” then separately “turn left 30.”
Expect
Pedal now moves into the turn (new this batch). Its sign is an unmeasured guess pending the slip-ball calibration flight — this block is exactly how that guess gets checked.
Record
Which pedal moved for which turn direction, and whether it coordinated the turn or fought it.

8 Unpark mid-turn carries on mode 2's set targets The prize

Do
Mode 2, set speed away from current (e.g. “speed 200” while slow), let the AI start accelerating, then unpark (switch off the AI-pilot wheel) while still accelerating/turning.
Expect
Mode 1 picks up flying immediately toward mode 2's set heading/speed/altitude — not whatever the aircraft happened to be doing at the instant of the switch. This is the fix for a real crash: an unpark mid-maneuver previously left the controls fixed with no correction, and the aircraft went down as bank increased unchecked.
Record
Did mode 1 visibly correct toward the held targets right away, with no dead interval?

9 A body-layer restart lets go of the stick

Do
While Petrovich holds mode 1 (or mode 2), restart body-layer (Ctrl-C and relaunch). Do this somewhere safe.
Expect
Restarting body-layer makes Petrovich let go: mode 1 frees the axes back to you, mode 2 drops its goal/CBTM/HVRT state back to ED's own AI. Confirm via the collector log and GET /ai_pilot_wheel/latest — apw_goal_seq/apw_cbtm_seq reset to the fresh process's values.
Record
Did the stick/controls come back cleanly, with nothing stuck?
