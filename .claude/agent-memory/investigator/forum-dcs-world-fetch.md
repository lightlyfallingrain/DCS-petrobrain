metadata:
  type: reference

Automated fetch of `forum.dcs.world` thread content (WebFetch or similar) has
consistently returned 403/blocked across multiple sessions (RasterCharts recon,
clipmap recon). Do not record an unfetched forum thread as an "unread gap" and move
on — per project convention, ask the user to open the URL manually and paste the
content back if the thread's content matters for resolving the current question.
WebSearch result titles/snippets are still useful as leads (forum-claim-unverified
evidence strength) even when the full thread can't be fetched.
