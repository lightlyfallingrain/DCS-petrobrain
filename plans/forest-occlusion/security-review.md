### Required Fixes (if any)

1. **Guard `ForestOcclusion` against non-finite `x`/`z` before `math.floor`** —
   `body-layer/src/perception/forest.py:80` (`_cache_cell_key`), reached from `occluded()`. A
   `NaN`/`Inf` candidate position (unvalidated anywhere upstream of this gate, and the belief layer
   has already had to explicitly guard this identical shape of input one layer downstream,
   `BL-B58`/`BL-B59`) raises `ValueError`/`OverflowError` out of the only poll loop
   (`main()`'s plain, non-`--console`/`--crew-text` path) that has no per-cycle exception guard —
   killing the perception logger for the rest of the sortie on a single malformed telemetry sample,
   once `--forest-occlusion` is on (which is Stage 2's entire purpose). Treat non-finite as
   not-occluded (fail open), consistent with this gate's own "`None` landcover is not forest"
   philosophy, rather than letting it raise.

This is a small, surgical fix (one `math.isfinite` check at one call site) and does not change the
plan's design, the cache shape, or any other gate. Per `AGENTS.md`, this fix re-enters
Implementer → Reviewer (review of the fix) → DoD; it does not go straight to DoD and the main loop
should not apply it directly.
