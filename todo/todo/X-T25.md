  **Two are at the limit, not one.** A `PostToolUse` hook asked **six** separate agents to compact
  `implementer/MEMORY.md` during the 2026-10-10/11 session and every one correctly declined, because
  the file's own header forbids a wholesale rewrite and records three past incidents caused by
  exactly that. Declining was right each time; the consequence is that nothing has reduced it and the
  hook will keep firing at every agent that writes a memory.

  **Why it matters rather than being housekeeping.** The index is what an agent reads to decide
  *which* memory file is relevant. Past the read limit it is truncated, so the entries at the end —
  the newest, which is to say everything learned most recently — become invisible, and the failure is
  silent: an agent repeats a mistake a memory exists to prevent and nothing indicates the index was
  cut. `docs/AGENT_WORKTREE_PROTOCOL.md` already records that an unwritten memory is the most
  expensive loss in this system; an unreadable one is the same loss with a file on disk to make it
  look handled.

  **What the pass has to respect, which is why it is its own task and not a line in someone else's:**

  - **The header's prohibition on wholesale rewrite stands.** The three incidents it cites are the
    reason. Compaction means shortening or merging *entries*, each judged on its own, not
    regenerating the file.
  - **One line per entry, ~150 characters**, per the format each role file states.
  - **Do not delete an entry to save bytes.** An entry whose memory file still exists but is no
    longer indexed is worse than either: the file is unreachable and nothing says so. If an entry
    goes, its file goes with it, deliberately.
  - **Candidates for merging**: entries recording the *same* lesson from different features. The
    2026-10-10/11 session alone added several to `implementer/` and `reviewer/` — the degenerate-
    fixture family, the counterfactual-must-be-run family, and the new
    earn-the-reason/cite-the-decomposition pair — which are plausibly one entry each rather than
    three.
  - **Its own worktree and branch**, since it touches no subproject's code.

  Worth considering as part of the same pass, rather than filing separately: whether the hook's
  threshold (it asks for under 17.1 KB) should instead warn at a size that leaves room, and whether
  a periodic compaction is a scheduled task rather than something discovered at the limit. Six
  declines in one session is the hook asking the wrong agent at the wrong moment — the same
  structural point `AGENTS.md` makes about rules that must be remembered when attention is
  elsewhere.
