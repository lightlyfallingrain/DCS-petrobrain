# X-B36 — `tools/` is outside every subproject's documented format/lint gate

- [ ] **Each subproject's documented check command is `ruff format --check src tests`, so real
  source shipped under `tools/` is never formatted or linted — and a file can pass "all checks" while
  being unformatted.** #status/open Filed 2026-10-15 from the `X-T26` review
  (`plans/configurable-constants/review.md`, required finding 2).

  **How it surfaced.** `X-T26` added `body-layer/tools/generate_defaults.py` — the generator that
  produces `config/defaults.toml` from the constants' own `#:` comments, so not a scratch script but
  a file the build depends on. It failed `ruff format --check` (4 reformats). The implementer's
  report of "pass" was *accurate* against the documented gate, which does not include `tools/`; the
  reviewer caught it only by running `ruff format --check .` over the whole subproject.

  **It is not local to body-layer.** `audio-adapter/`, `brain-layer/` and `world-model/` all have a
  `tools/` directory too, which is why this was not fixed inside `X-T26`'s own merge — widening one
  subproject's gate while three others keep the hole would make the convention less predictable, not
  more.

  **A naive widening breaks immediately, and this is the part worth knowing before starting.**
  `ruff format --check .` over `body-layer` today fails on
  `body-layer/research/2026-10-05-security-audit.md` — a research note whose illustrative code blocks
  ruff reads and reformats. So the fix is not `.` in place of `src tests`; it needs an explicit
  scope, either naming `tools` alongside `src tests` or excluding `research/` in each subproject's
  `pyproject.toml`. The second is probably better, since `research/` holding
  deliberately-unformatted example code is a standing property of this repo rather than one file's
  accident.

  **Where the change lands:** each subproject's own `CLAUDE.md` "Commands" section, and
  `.claude/scripts/commit-quality-gate.sh`, which enforces the same sequence mechanically at commit
  time. Those two must agree — the gate script is what actually stops a bad commit, and the
  `CLAUDE.md` text is what a session reads to self-verify earlier.
