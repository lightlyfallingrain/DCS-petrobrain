# brain-layer

Petrovich's second, slow, deliberative loop -- turns free-text speech
`body-layer` could not parse deterministically into one of three honest
responses (`unable <reason>`, `confirm <command>?`, `which one`), without
ever blocking the 5 Hz perception loop and without ever inventing world
state.

See `plans/brain-layer/plan.md` for the full design (`BR-1`) and
`brain-layer/CLAUDE.md` for how to run and test this subproject.
