# BL-B118 — Set the operator altimeter's pressure to the mission's QNH at mission start

- [x] **BL-B118 — At every mission start, ground or air, Petrovich sets the operator (copilot)
  barometric altimeter's pressure setting to the mission's QNH, closing a self-calibrating loop on
  the operator Baro Pressure Knob (device 42, command 3001, arg 834's readout).** #status/done
  #needs-flight Filed 2026-11-16 as a `[[BL-16]]` sub-item, branch `feature/bl16-qnh-mission-start`,
  plan `plans/bl16-qnh-mission-start/plan.md`. **DoD PASSED 2026-11-16, merged to `main` as
  `10c32d91`** (tree identical to the DoD-tested tree outside `.claude/`). Branch to fly: `main`.

  **Why.** The pilot's own theory, after the `BL-16` takeover-fix sorties kept reproducing a wild
  barometric target on the first "Request Aircraft Control" toggle: *"AI takes the barometric alt
  from the copilot's altimeter, I think. If the pressure setting there is incorrect, the
  barometric alt value is wildly off. This means that when mission starts, Petrovich must set
  altimeter pressure setting to the actual pressure value from weather or briefing."*
  (`docs/acceptance/2026-11-16-bl16-batch-a-feedback.md`, "The barometric bug"). Explore settled
  it: *"1 use QNH for copilot / 2 set at mission start, both ground start and air start / 3 moves
  steadily"* — and the pilot explicitly declined a probe flight first (*"Skip the probe, just
  build setting QNH."*), so the first live flight is this feature's own test.

  **Shape.** `env.mission.weather.qnh` (mmHg) is read the same way the mission-start Hook already
  reads `env.mission.theatre`, and the loop uses only existing write/read channels
  (`write_cockpit_switch`, `read_args`) — no new `Export.lua` code, which matters while that file
  sits at Lua 5.1's 200-local ceiling (`[[AC-B12]]`). The device's gain (mmHg per knob-delta) is
  unmeasured, so the loop is self-calibrating (secant method) rather than fixed-gain, with bounded
  step size, iteration count and wall-clock duration, and fails loud — one spoken "unable" line —
  rather than silently if the knob never responds (the open risk: whether device 42 accepts the
  write from the pilot seat at all). Full design: `plans/bl16-qnh-mission-start/plan.md`.
