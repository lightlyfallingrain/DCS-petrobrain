# BL-B45 — The `"Safe from <threat>"` close-out call

- [ ] **BL-B45 — The *"Safe from &lt;threat&gt;"* close-out call, sourced from mission memory.
  GATED ON [[BL-8]].** #status/open User direction 2026-10-08, answering `Q8`:

  > *"mission memory will let Petrovich remember where that threat was -> safe from is realistic. But
  > only from mission memory, that is needed first."*

  This settles `Q8` rather than picking a side. The reviewer's case is **accepted in principle** — a
  pilot who heard *"Danger"* is owed the *"Safe from"* that closes it, because an unclosed warning
  leaves them believing they are still inside an envelope they have left. The current narrowing
  (entering transition only) is right **for now**, for a reason neither side of the original argument
  stated: a close-out call about a threat he can no longer see is only honest if he *remembers where
  it was*, and that memory does not exist yet.

  **Do not take the one-line reversal before [[BL-8]].** Doing so would reintroduce the exact
  no-omniscience violation the observability gate was built to close — he would be announcing a
  classification and a position for something the cockpit mask says he cannot see. Once the memory
  layer can supply a remembered threat position, the licence becomes "a threat-envelope transition
  either way, where the leaving call is sourced from mission memory", and that sentence replaces the
  current docstring bar.
