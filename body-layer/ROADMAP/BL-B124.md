  **What was built**: sun elevation derived from the mission's own date + wall clock (read from the
  firing-events Hook's existing 1 Hz scripting-state poll, not a `.miz`/MI-3/MI-6 thread — Stage 1,
  amended 2026-11-25) and ownship lat/lon; an anchored, per-optic `light_factor(optic,
  sun_elevation_deg)` curve (Stage 2, pure/unit-tested astronomy); threaded through
  `tier_ranges()`/`check_visibility()`/`optic_policy.py`'s whole decision chain, each optic
  resolving its own factor rather than sharing one value (Stage 3, Stage 4's own fix over the
  plan's original single-tuple design); and a new `EmitterKind.LAUNCH_FLASH` so a missile/rocket
  launch is a presence-only night light source out to the player bubble, reusing the existing
  emitter-bypass mechanism that already did this for firing/burning (Stage 5). `EmitterKind.
  EXPLOSION` (Stage 6, U1) was deferred to `[[BL-B136]]` before implementation began — new Hook
  plumbing `S_EVENT_HIT` doesn't ship today, unlike the other three light sources which needed zero
  new DCS reads.

  **Second-order effect on the next milestone**: `tier_ranges()` now carries a composable
  `light_factor` slot — `[[BL-B138]]` (weather) and any future BL-B22 factor-3 work reuse this same
  slot rather than inventing a second multiplier chain; this is the first of three condition
  factors BL-B22 named, and the plumbing decision (per-optic, per-tier, not a single flat
  multiplier) is now settled by this feature rather than left open for the next one to re-decide.
