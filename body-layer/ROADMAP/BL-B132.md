# BL-B132 — Readable cockpit args in the switch reference

- [ ] **Readable cockpit args in the switch reference.** #status/open Filed 2026-11-19 by user direction: *"@body-layer/config/sequences/mi-24p/switch-reference.md lists the effecors we can *write*. It'd be really good to add to that list args that we can *read*, like lamps, instrument values (like the rotor rpm), etc."* The reference today is generated (`body-layer/tools/render_switch_reference.py`) from the clickable-control dump only. Readable args are the gauges and lamps declared in the module's `mainpanel_init.lua` (draw args read via `GetDevice(0):get_argument_value`, already served by `POST /query/read_args` and `GET /watched_args/latest`), plus `list_cockpit_params()`'s `BASE_SENSOR_*` values. First consumer: `[[BL-16]]` mode 1's rotor RPM floor, which uses an engine-RPM proxy (`BASE_SENSOR_LEFT_ENGINE_RPM`) until the real rotor RPM reading is known. Step 1 is recon (investigator, `aircraft-layer/research/`); step 2 extends the generator.
