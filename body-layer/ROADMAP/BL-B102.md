# BL-B102 — "that" / "it" in a command means the contact Petrovich last talked about

- [~] **BL-B102 — When the player uses "that" or "it" in a command, it refers to the contact (or
  group) Petrovich was last talking about.** #status/in-progress User request, 2026-10-26, branch
  `feature/that-it-referent`. The user's words, verbatim:

  > *"When plyaer commands an action and uses "that" or "it", those refer to the contact Petrovich
  > was last talking about.*
  >
  > *Like*
  > *- Petrovich: "AAA 2 o'clock, far"*
  > *- Player: "where is it/that?" <- it means the AAA unit*
  > *- Ptrovich: "<o'clock> <distance in km> <world ref>"*
  >
  > *- Petrovich: "unit in 11 o'clock group is armor"*
  > *- Player: "target that/it" <- that is the armor unit*
  > *- Player: "follow that group" <- that is the group becouse it was specified*
  >
  > *- Player: "describe"*
  > *- Petrovich: "group 11 o'clock, armor and trucks. Group 2 o'clock, armor, moving east"*
  > *- Player: "follows that moving group"*
  > *- Player: "engage that 11 o'clock armor, missiles"*
  >
  > *The above are examples, do not build commands for these. Instead build the that/it logic
  > (unless that already works)."*

  **Scope: the referent logic, not new commands.** The examples illustrate the resolution; the
  verbs in them are not a build list.

  **Does it already work? No.** Measured from code, 2026-10-26:

  - Spoken lines reach `CrewConsole._print` as bare strings — nothing records *which* contact or
    group a line was about, so there is nothing for "it" to point at.
  - `belief/utterance.py::_strip_filler` drops a leading "that" and searches classifications
    ("where's that shilka") — a type search, not a referent.
  - `where_is_it` ("where is it") is bound to the **attack target** (`plans/attack-run-los/plan.md`
    F3), and answers "No target" when none is set.
  - `CrewConsole.last_command_target_contact_id` is per-dispatch bookkeeping for `body.py`, reset
    before every command — not a conversational referent.

  **Prior design this builds on, not reinvents:** `plans/inbound-speech/plan.md`, "Command
  chaining" (2026-09-20) — resolve in **body**, never in `audio-adapter`'s stateless matcher;
  referents expire and die with their subject (a `lost` contact cannot still be "that one" — that
  would be an omniscience leak); ambiguity asks rather than guesses. And
  `plans/brain-layer/explore-notes.md` §4, "conversational memory is in scope".

  Decisions from the explore: `plans/that-it-referent/explore-notes.md`.
