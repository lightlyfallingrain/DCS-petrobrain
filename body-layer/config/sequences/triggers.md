# Effector-sequence triggers

GENERATED by `body-layer/tools/render_triggers.py`. DO NOT HAND-EDIT.
Source: `belief.effector_sequences.EffectorTrigger`/`TRIGGER_INFO` -- the single place a trigger is declared.
Regenerate with: `python tools/render_triggers.py --write`

Every trigger a sequence file's `run-on-trigger` header cell may name,
one row per trigger. A trigger fires on the **transition** into the
state it names, never while that state merely holds -- `takeoff` fires
the instant the aircraft leaves the ground, not for every poll it stays
airborne. Sequences for one trigger queue per trigger (firing a
trigger that is already running queues a re-run; it never runs two
copies at once, and never collides with a different trigger's own
queue). A sequence file naming a trigger not listed here is a bad
file -- see `belief.effector_sequences.load_sequences`.

| Trigger | Fires when | Cardinality |
| --- | --- | --- |
| `takeoff` | Every time the aircraft leaves the ground (on-ground true -> false). No per-mission latch: a repeat takeoff or a warm air start re-fires it, and the engine's own implicit self-check --a row does not write if its switch is already observed at the target value -- makes an already-satisfied repeat a no-op, with no explicit condition needed in the sequence file itself. | every time |
| `observ-on` | The pilot commands "Observ on", and the guidance unit is ready (refused outright, without firing this trigger, if it is not). | every time |
| `observ-off` | The pilot commands "Observ off". A violent manoeuvre can also force OBSERV off automatically, but that path does not fire this trigger -- it is the pilot-commanded path only. | every time |
| `weapons-arm` | The pilot commands "weapons armed", or starts an attack run ("engage"), which arms the weapons safety bar automatically. | every time |
| `weapons-safe` | The pilot commands "weapons safe". | every time |
